# API Watcher Privacy Policy

**Effective date: September 18, 2026**

API Watcher is a developer utility that monitors public API documentation and changelog pages.

## Information we collect

The current Android MVP does not require an account and does not collect names, email addresses, contacts, location, advertising identifiers, or payment information.

The app sends network requests to the API Watcher service to retrieve monitored API information. The service may process public changelog data from the monitored sources.

## Notifications

The initial release does not require notification permission and does not send advertising notifications.

## Third-party services

API Watcher monitors publicly available pages operated by third parties. Those services have their own privacy policies and terms.

## Data retention

The Android MVP does not store personal user data on the device beyond normal Android application state.

## Contact

For privacy questions, open an issue in the API Watcher GitHub repository.

This policy may be updated as the product gains features such as accounts, subscriptions, or push notifications. Any future release will update the policy and Play Console disclosures as required.
